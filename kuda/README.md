# 🧭 Куда идти

Android-приложение, которое помогает вернуться к запомненному месту:
к машине на парковке, отелю в незнакомом городе, палатке в лесу.

- «📍 Запомнить место» сохраняет текущие координаты под понятным именем;
- большая стрелка показывает, куда идти, и сколько метров осталось;
- можно хранить несколько мест и переключаться между ними;
- место можно открыть на карте или отправить другу;
- работает без интернета — нужен только GPS.

## Как установить

Скачайте свежий `kuda.apk` во вкладке **Releases** и откройте его на телефоне.

## Сборка

```
./gradlew assembleDebug
```
