# ✨ Сказочник

Android-приложение, которое сочиняет сказку, где ребёнок — главный герой,
и читает её вслух. Работает без интернета.

- имя ребёнка, мальчик или девочка;
- выбор друга-героя: дракон, кот, единорог, робот, лиса, динозавр;
- случайный сюжет из набора мест, приключений и концовок;
- озвучка встроенным синтезом речи Android.

## Как установить

1. Откройте вкладку **Releases** в репозитории и скачайте свежий `skazochnik.apk`.
2. Откройте файл на телефоне. Android попросит разрешить установку из этого источника — разрешите.

Если озвучка не работает, установите русский голос:
Настройки → Специальные возможности (или Язык и ввод) → Синтез речи.

## Сборка

```
./gradlew assembleDebug
```

APK собирается автоматически GitHub Actions при каждом изменении в папке `skazochnik/`.
